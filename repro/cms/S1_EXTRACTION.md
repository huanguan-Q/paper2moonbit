# S1 算法抽取清单 — Count-Min Sketch（Cormode & Muthukrishnan, 2005）

> 复现用途：仅取算法的**定义性判据**（数学定义与论文定理），不转存论文正文。

## 可转核心

| # | 组件 | 定义 |
|---|------|------|
| C1 | 结构 | d × w 计数器矩阵，d 个成对独立哈希 |
| C2 | 更新 | add(a, c)：对每行 i，counters[i][h_i(a)] += c |
| C3 | 查询 | estimate(a) = min_i counters[i][h_i(a)] |
| C4 | 参数 | w = ceil(e/eps)，d = ceil(ln(1/delta)) |
| C5 | 合并 | 同种子两 sketch 逐格相加，total 相加 |

## 测试判据（论文判据，S4 落为测试）

| ID | 判据 | 来源 |
|----|------|------|
| T1 | 小流量流上估计与精确计数**逐项相等**（朴素 oracle 对拍） | 定义 |
| T2 | **单侧误差**：estimate(a) ≥ true(a) 恒成立（永不高估之外的相反方向） | 论文定理 |
| T3 | **行和守恒**：每行计数之和 = 流总长度 N | 定义 |
| T4 | **εN 误差界**：w/d 按 C4 取，跨种子成功率 ≥ 1-δ | 论文定理 |
| T5 | **确定性**：同种子同输入 → 同结果 | 实现要求 |
| T6 | **合并正确性**：merge 后 estimate = 两流合并后的 estimate | 论文 §merge |

## 边界与偏差预登记

- 哈希用确定性混合函数模拟成对独立（非真随机族），T4 用多颗种子做经验成功率
- 计数器用 Int（不模拟溢出回绕），超大流不在判据范围
