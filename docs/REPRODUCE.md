## 6. 客观限制（必须连同结论一起读）

1. **非盲**：Count-Min Sketch 是我已知的经典结构。真正的检验应选一篇我无法凭记忆复述的论文。
2. **跳过 S1 成本**：我没有读论文 PDF，抽取清单来自先验知识。原始轮次里最贵的一步（理解 + 判据化）被跳过了，所以"2 分钟"不能拿来论证效率。
3. **同源**：复现者与被检验者是同一个模型，不是第三方独立复现。
4. **判据自选**：判据集由我在看既有实现**之前**拟定（这点是受控的），但没有对既有判据集做预注册，因此 §5 的"只有 3 条重合"部分反映的是选择差异。
5. **n=1**：单次运行不构成稳定性证据。
