# METHODOLOGY — 论文判据驱动的 MoonBit 实现工作流

本文档描述 paper2moonbit 的七阶段流水线、判据哲学与三条实现路由。所有环节都经过 26 轮真实论文试跑（R1–R26）验证。

## 1. 七阶段流水线

### S0 环境自检
- `moon version` 确认工具链；知识库核对当前版本的 API 断言是否仍成立
- 升级场景：先跑 `regress.sh` 全量回归 + `moonprobe/` 边界探针，确认基线

### S1 论文抽取（EXTRACTION.md）
- 下载论文（RFC 优先于 ACM/IEEE——原作者撰写、伪代码更精确、永远可访问；学术主页/INRIA/Oracle 合法托管为镜像候选）
- 抽取**可转核心**（逐条标注论文出处：章节号/伪代码出处/常数）
- 预登记**测试判据**（见 §2 判据哲学）
- 预登记**偏差声明**（哪些不做、哪些替换、为什么）
- 预登记 **FORMAL 候选**与预期结果

### S2 蓝图（BLUEPRINT.md）
- 文件清单与依赖序（spec-first：测试文件先于实现）
- 判据→测试的映射表
- 明确不实现清单（反范围蔓延）

### S3 蓝图确认
- 用户/评审确认后再生成——算法范围与偏差在此时锁定

### S4 规格先行
- 测试文件先写，全部判据落为可执行断言
- 契约式：每个 test 对应一条论文判据或定义性判据

### S5 生成
- 按蓝图实现；API 名不确定时**探针驱动**（写最小 probe 文件跑 `moon check`）
- 已知配方失效场景（第 14/20 轮教训）：文献公式依赖操作数尺度前提、编译器语义差异——极端尺度随机流测试是击穿手

### S6 验证闭环
- `moon check` 零错误零警告 → `moon test` 全绿 → `moon prove` 契约
- 失败诊断配方：最小失败对二分（第 14 轮 TwoSum 尺度击穿）、Python 参考实现镜像对照（第 20 轮 SA-IS）

### S7 质量门 + 发布
- `moon fmt` → `moon check` 零警告 → `moon test` 全绿 → `moon prove` 契约达成
- mooncakes 发布：description/keywords/license/readme 完整；409 冲突 bump 版本
- 合规三查（见 COMPLIANCE.md）

## 2. 判据哲学

论文判据按**可信度分层**，全部在 S1 预登记、S4 落为断言：

| 层级 | 类型 | 例 |
|---|---|---|
| 1 | 规范测试向量（逐字节） | RFC 8439 ChaCha20 密文、RFC 8289 CoDel 状态机序列 |
| 2 | 论文 worked example | BWT abraca→caraab、Skip List 几何分布统计窗口 |
| 3 | 定义性判据 | SA 是排列且有序、CMS 单侧误差、哈希成员封闭 |
| 4 | 朴素 oracle 对拍 | O(n²) 参考 vs 线性实现，随机流全称一致 |
| 5 | 性质化（quickcheck） | 一致性哈希单调性/平滑性、成员封闭 |
| 6 | 端到端伺服 | CoDel 稳态 min sojourn ≤ TARGET + 利用率 ≥ 0.5 |

原则：
- **定理拆两类**：全称精确断言（单侧性、恒等式）与窗口断言（概率界 → 常数因子 + 固定种子）
- **免费不变量优先**：行和守恒（CMS）、长度守恒（BWT）这类线性不变量是最强的免费判据
- **论文常数缺失时降级**：SuperLogLog 截断常数无闭式 → 降级到论文明确陈述的相邻性质（降分散度、机制方向性）
- **极端尺度随机流**：文献公式的浮点精确性依赖操作数尺度关系（第 14 轮实测 TwoSum 在 b≪ulp(a) 时失效）——跨 binade 随机流是必配判据

## 3. 三条实现路由

### 主线路径
算法/数据结构/解析器/协议类论文，纯逻辑无重型依赖：判据 → 实现 → 质量门。已验证 13 类。

### 降级路径（系统工程类）
论文含不可复现组件（真实网络、LLM、内核）：
- **环境 stub 化**：确定性离散事件模拟（CoDel 的 AIMD 发送器 + 链路）、行为近似 stub（RQGM 的 LLM 桩）
- **算法核心全量实现**（CoDel 控制律逐行）
- **端到端伺服判据**替代真实世界观测
- 第 15 轮验证：该路线与 LLM stub 模式同构，适用于全部系统工程类论文

### FORMAL 路径（能力边界已标定）
- **可证**：Int + div/mod + FixedArray 上的恒等式、范围界、LIA 保底
- **不可证**（阳性对照确认）：Double 域 `==`（Error 4207）、BigInt 域表达式、.mbtp 路径 lambda 与裸布尔 `&&`
- **行为陷阱**：Double 契约错误具有阻断性（同包其余探针全部不跑）；Timeout 的常见真因是契约缺前提而非求解器抖动
- 复检工具：`moonprobe/` 项目含全部 6 类边界探针，moon 升级后一键重标定

## 4. 已验证的配方沉淀（选摘）

- 规范源优先级：RFC > 作者学术主页 > INRIA/Oracle 存档 > 付费墙（降级声明）
- spec-first：测试文件先于实现文件生成
- API 不确定 → 探针文件批量验证（一次 `moon check` 试多个候选名）
- Python 参考实现镜像：复杂算法先在 Python 验证逻辑再机械翻译（第 20 轮 SA-IS）
- 合规三查：思想/表达二分自查、源许可核查、RFC 版权注记（详见 COMPLIANCE.md）
- 工具链升级协议：regress.sh 全量 + moonprobe 边界重标定
